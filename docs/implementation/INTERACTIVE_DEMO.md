# 인터랙티브 데모 실행·검증 안내

## 범위

[승인된 데모 결정](../decisions/2026-09-21-interactive-demo.md)에 따라 별도 `/demo` 경로를 제공한다.
실제 Google 로그인·Supabase 저장·사진 검수·보상 지급이 없는 발표용 시연이다.
Day 12로 고정되며 이전 11일의 1,100점은 샘플이다. 오늘의 촬영을 데모 제출하면
1,200점이 되어 홈·보드·결과에 동일하게 표시된다. 이후 일차로 날짜를 이동하지 않는다.

## 로컬 실행

Node/npm 버전과 설치는 [개발 안내](../DEVELOPMENT.md)를 따른다. 기존 `.env.local`을 덮어쓰지 않는다.
PowerShell에서 이 실행에만 데모를 켤 수 있다.

```powershell
$env:ENABLE_DEMO = 'true'
npm run dev
```

브라우저에서 `http://localhost:3000/demo`를 연다. 기본 `/`는 실제 서비스 경로이며 데모로 자동 전환하지 않는다.
서버가 다른 포트로 실행되면 출력된 포트의 `/demo`로 접근한다.
Supabase URL/key, Google 설정은 데모에 필요 없다. `PROOVIT_LOCAL_PREVIEW`와 `ENABLE_UI_PREVIEW`는 켜지 않아도 된다.
공개 시연 시에는 배포 환경에 `ENABLE_DEMO=true`만 별도로 설정하고 HTTPS `/demo` 주소를 공유한다.
이번 작업에서 실제 배포 설정·운영 연결은 실행하지 않았다.

종료 후 같은 PowerShell에서 필요하면 `Remove-Item Env:ENABLE_DEMO`로 실행용 환경변수만 제거한다.
서버를 재시작해야 flag 변경이 반영된다. 비활성 시 not-found 화면이며 Next streaming 응답 특성상
HTTP 200으로 전달될 수도 있다. 핵심 차단 기준은 데모 UI/기능을 렌더하지 않는 것이다.

## 시연 순서

1. 데모로 시작 → 가상 참가자·챌린지 참가 상태 확인.
2. 오늘의 미션 보기 → 오늘의 제출·완료 기준 확인.
3. 카메라로 인증하기 → 권한 허용 → 촬영 → 미리보기 → 필요 시 재촬영.
4. 데모 제출하기 → 결과 100점/누적 1,200점 확인.
5. 홈과 미션보드에서 동일 점수 및 Day 12 완료 확인.
6. 새로고침해도 진행 유지. 완료 미션을 다시 열어도 추가 점수 없음.
7. 내 데모 → 데모 초기화 → 확인 → 다시 시작하면 초기 1,100점 시나리오.

사진은 메모리에서만 다루며 서버로 전송하지 않는다. 브라우저 저장에는 `proovit.demo.v1` 키로
version/entered/completedToday만 기록한다. 초기화는 이 키만 바꾸며 실제 계정/다른 데이터를 지우지 않는다.
저장 차단 시 안내 후 현재 페이지 세션에서만 진행하며 새로고침 시 상태 유실/이전 저장 상태 복원이 가능하다.
여러 탭에서 저장 변경을 받아 표시를 갱신하지만, 서버 트랜잭션이나 여러 기기 동기화는 제공하지 않는다.

## 검증과 제한

- `npm run check`: 상태/중복/저장 데이터 검증과 기존 DB·Proof 단위/통합 포함.
- `npm run build`: 실제 서비스와 데모를 함께 빌드.
- `npm run test:e2e`: 백엔드 미설정, 데모 활성. 촬영 모의 스트림, POST 없음, 진행 저장·초기화·손상/차단·320px/키보드, 기존 프리뷰 회귀.
- `npm run test:e2e:participant`: 테스트 전용 backend, 데모 비활성. 실제 라우트 회귀와 데모 진입 차단.
- Windows에서 샌드박스 권한 부족으로 Playwright 서버 종료가 지연될 수 있다. 이번 검증은 프로세스 정리 권한으로 재실행한다. 테스트를 skip하거나 CI 검사를 삭제하지 않는다.
- 위 테스트의 카메라·백엔드는 모의 환경이다. 실제 Galaxy Chrome/iPhone Safari의 HTTPS 권한 허용/거부·촬영·재촬영·이탈 후 카메라 표시 종료는 배포 후 사람이 확인해야 한다.
- 독립 리뷰, 원격 CI, 병합, HTTPS 배포, 실기기 검증은 별도 단계다.
