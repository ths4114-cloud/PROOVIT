# 하단 네비게이션 수정

- 사용자 지적: 전달한 긴 홈 이미지에서 네비게이션이 본문 중간을 가림.
- 원인: 모바일 `position: fixed` 메뉴를 fullPage 스크린샷에 포함하면 원래 viewport 하단 위치에 메뉴가 찍히고 그 아래로 문서가 계속 나타남. 데스크톱은 별도 sticky/음수 margin 방식을 사용함. 이전 시각 검수가 이 문제를 놓쳤음.
- 수정: 화면 높이의 app-shell 안에서 header / 스크롤 가능한 main / bottom-nav를 분리. 메뉴는 본문과 겹치지 않는 전용 하단 행. 모바일·데스크톱 모두 동일 구조. 안전 영역 여백 유지. 오프라인 배너도 화면 높이를 밀어내지 않음.
- 미리보기: 긴 전체 문서 대신 실제 viewport를 촬영. 첫 화면과 본문 끝으로 스크롤한 화면을 따로 제공.
- 회귀 검증: 360/390/1280px에서 본문 위·중간·끝의 메뉴 y좌표 유지, 본문 하단 <= 메뉴 상단, 창 자체 스크롤 0, 화면 크기 변경·키보드 포커스 후 메뉴 하단 좌표 확인.
- 검증: production build/TypeScript 및 lint 통과. 기존 6개 E2E + 네비게이션 회귀 1개 통과. DB/인증 로직 변경 없음.
- 범위: globals.css, 브라우저 테스트/미리보기, 인계 기록. Level 1 UI 수정. 원격 push/배포 없음.
- 브랜치: `fix/navigation-layout`, base `feat/participant-pwa`의 `f441176`. Feature Owner: 민 담당 범위, 검토: Codex 자체 점검. 팀 사람 Reviewer/원격 Issue 미지정.
- 추가 시각 확인: 내부 스크롤/viewport 변경 후 메뉴 캡처가 간헐적으로 비던 backdrop-filter를 제거하고 불투명 배경으로 교체. 최종 모바일 첫 화면·스크롤 끝·데스크톱 캡처에서 메뉴 표시 확인. 최종 E2E 7/7 통과(17.0초).
